01 · Fundamentals

Core Web & Network Entities

The Internet is the infrastructure; the World Wide Web is an information system that runs across it.

Internet

A global network of networks that links computers and devices using shared communication protocols.

World Wide Web

An information system of linked resources accessed over the Internet through browsers and web protocols.

W3C

The World Wide Web Consortium, which develops open standards for an accessible and interoperable Web.

Web Page

A single document, usually written in HTML, that a browser can request, render, and display.

Website

A collection of related web pages and assets published under a common domain name.

Home Page

The welcoming or default page of a website, helping visitors understand where to begin.

Index Page

A directory-like entry page, commonly named index.html, served when no specific file is requested.

Landing Page

A focused page designed for a specific visitor action, such as signing up or learning more.

Every website is part of the Web, but the Web is only one service built on top of the Internet.
02 · Request flow

Clients, Servers & Domains

A page load is a conversation: a client asks, a server responds, and naming systems help the request find its destination.

Step 01Ask

A Web Browser requests a resource using a URL.

Step 02Resolve

DNS maps the domain to an IP Address.

Step 03Respond

A Web Server returns the requested page.

Web Browser

Client software that requests resources and turns HTML, CSS, and JavaScript into a usable interface.

Web Server

A computer and software stack that stores, processes, and delivers web resources to clients.

Web Domain

A human-friendly name, such as example.com, that identifies a site within DNS.

URL

A Uniform Resource Locator that tells a browser where a resource is and how to retrieve it.

URI

A Uniform Resource Identifier: the broader standard for identifying a resource by location, name, or both.

IP Address

A numerical address assigned to a device, such as 203.0.113.10, so packets can be routed to it.

DNS

The Domain Name System translates memorable domain names into IP addresses.

NSlookup

A command-line diagnostic tool for querying DNS records and checking how a name resolves.

One address, many clues In https://example.com/news, the scheme is https, the domain is example.com, and /news is the path.
A quick DNS lookup
nslookup example.com
# Ask the configured DNS resolver for the domain's address.
03 · Network layer

Protocols & Security

Protocols are agreed rules. They let different machines exchange information predictably, while security layers protect that exchange.

HTTP

Hypertext Transfer Protocol. The request-and-response language used to transfer web resources between clients and servers.

HTTPS

HTTP Secure. It uses encryption and authentication to make web communication safer against interception and tampering.

SSL

Secure Sockets Layer. An older predecessor to TLS that introduced encrypted communication for online connections.

TLS

Transport Layer Security. The modern cryptographic protocol used by HTTPS to protect data in transit.

Why the padlock matters HTTPS does not guarantee that a site is honest, but it helps confirm server identity and keeps the connection private from casual observers.
04 · Authoring & discovery

Web Technologies & Search

The visible page is authored, discovered, and connected through a small set of powerful technologies and conventions.

HTML

HyperText Markup Language gives a document structure and meaning. Semantic elements help both people and software understand its organization.

Structure before styling

Headings create a readable outline, while paragraphs hold ideas and landmarks help visitors move through the page.

Meaningful elements

Choosing an element for its meaning makes a document more accessible and easier to maintain.

Small details matter

A well-shaped document gives every reader a clearer path through the same information.

The full HTML boilerplate
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
  </head>
  <body>
    <h1>Hello, Web</h1>
  </body>
</html>

Search Engines

Services that crawl, index, and rank web content so people can find relevant answers through queries.

ChatGPT

An AI conversational system that can explain concepts, generate drafts, and help people explore information through natural language.

Hyperlinks / Links

Clickable references that connect one resource to another. Visit MDN's HTML reference.

Keep exploring The best way to learn the Web is to inspect it. Open a page's source, follow a link, and notice how a browser turns a document into an experience.
